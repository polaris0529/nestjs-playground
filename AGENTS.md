## OVERVIEW
WorkFlow is a NestJS 11 admin portal with PostgreSQL, TypeORM migrations, Handlebars SSR, cookie JWT auth, CSRF, i18n, and Docker deployment. Treat `src/`, `views/`, `public/`, and `scripts/` as source; treat `.build/` (compiled output, deploy packet, coverage, test output) as generated/runtime artifacts unless explicitly asked.

## CONVENTIONS

- Follow `CLAUDE.md` and `.claude/rules/`; user-facing status is Korean.
- Make the smallest useful change and do not refactor adjacent code without a direct need.
- Use TypeScript/Nest layering: Controller -> Service -> Repository. Controllers never use repositories or TypeORM directly.
- `@InjectRepository` belongs only in repository classes; services depend on local `*.repository.ts`.
- Feature modules register controllers, services, repositories, and entities with `TypeOrmModule.forFeature([Entity])`.
- Use kebab-case filenames, DTO names like `CreateMenuDto`, and explicit `@Entity('<table>')` names.
- Services and lower layers throw i18n keys, not localized strings.
- REST routes are resource-oriented: `GET` read, `POST` create, `PATCH` partial update, `DELETE` remove.
- Schema changes require migrations under `src/database/migrations/`; keep `synchronize: false`.

## ANTI-PATTERNS

- Do not commit `.env`, secrets, `.build/`, or `node_modules/`.
- Do not add inline `<script>` blocks or inline event handlers in hbs templates.
- Do not hardcode UI colors outside the theme tokens in `.claude/rules/ui-design.md`.
- Do not change the header/sidebar/main/footer layout except for `login.hbs`.
- Do not store plaintext passwords or hardcode JWT/database secrets.
- Do not use `latest` Docker images; compose services need `container_name`, health checks where readiness matters, and internal DB ports.
- Do not put real domains, public URLs, or public IPs in `README.md`.
